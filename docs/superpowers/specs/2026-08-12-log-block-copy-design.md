# Android 日志整块复制设计

## 目标

解决桌面端日志表格中每条记录由独立 SwiftUI 视图渲染，导致用户只能逐行选择和复制的问题。

## 交互设计

- 保留现有表格模式作为默认浏览方式。
- 增加“纯文本”模式，把当前搜索和级别筛选后的日志合并为一个连续、只读、可选择的文本区域。
- 增加“复制当前结果”按钮，一次复制全部当前筛选结果，并短暂显示复制成功反馈。
- 每条复制内容依次包含时间、级别、Tag 和消息，以 Tab 分隔、换行分隔记录。
- 不包含已经从界面移除的 PID/TID。
- 空字段显示 `-`；消息为空时回退到原始日志内容。

## 边界

- 不修改 Logcat 后端、轮询、过滤或清理逻辑。
- 不持久化日志，也不增加自动导出。
- 复制范围始终跟随当前搜索和最低级别筛选结果。

## 验收

- 纯文本模式可以跨多条日志拖选，并支持 `Command-A`、`Command-C`。
- “复制当前结果”写入剪贴板的文本与当前筛选结果一致。
- 表格模式、暂停、清空、搜索和自动滚动保持可用。
- Swift 测试和桌面 App 构建通过。
