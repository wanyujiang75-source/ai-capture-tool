# Android 日志整块复制实施计划

## Task 1：可复制文本格式

- 在 Swift 测试中定义多条日志拼接、空字段和 raw 回退的期望结果。
- 先运行测试确认缺少格式化实现而失败。
- 新增独立格式化器并让测试通过。

## Task 2：桌面端复制交互

- 在日志工具栏增加“表格 / 纯文本”切换。
- 增加“复制当前结果”按钮和短时成功反馈。
- 纯文本模式使用单个可选择文本区域展示当前筛选结果。
- 保持表格模式默认行为不变。

## Task 3：验收

- 运行完整 Swift 测试。
- 构建 `AI抓包工具.app`。
- 启动桌面端，验证模式切换、跨行选择和剪贴板内容。
