# 发行包安装说明规格

## 目标

用户下载并解压 GitHub Release 的桌面 ZIP 后，不访问仓库也能看到安装前置条件和完整的首次使用步骤。

## ZIP 结构

ZIP 根目录固定包含：

- `抓包工具.app`
- `安装说明.md`

不增加用户数据、APK、抓包结果、本机配置或凭据。

## 说明内容

`安装说明.md` 至少包含以下章节：

- `前置准备条件`
- `安装步骤`
- `首次使用`
- `常见问题`

内容必须说明：

- 仅支持 macOS 14+ 与 Apple Silicon。
- 推荐内存、磁盘空间和网络条件。
- App 已包含本机抓包运行时，不要求用户单独安装 Python、Frida 或 mitmproxy。
- 新主机仍需 Android Studio/Android SDK，并接受 SDK License；默认设备需使用 arm64 Google Play 镜像。
- 内部开发签名包的 macOS 安全放行步骤，不建议关闭 Gatekeeper 或删除隔离属性。
- 首次准备模拟器、手动解锁与 Google 登录、安装应用、开始/停止抓包和查看接口/日志的流程。
- 数据目录和升级保护边界。

## 验收

- 打包测试先在旧实现上因 ZIP 缺少说明而失败。
- `release/package.sh` 生成的开发 ZIP 解压后包含两个根目录条目。
- 说明文件包含必需章节，不包含本机用户路径或凭据。
- ZIP SHA-256、解压后应用深度签名、arm64 架构和冷启动通过。
- GitHub Release 资产摘要与本地文件一致。
