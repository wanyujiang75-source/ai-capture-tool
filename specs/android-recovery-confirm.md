# Android 真机网络恢复确认

现有自动恢复规则保持不变。对当前和历史待恢复设备，增加“确认当前网络正常”按钮，先提示用户自行确认手机网络并二次确认；标明该操作不验证互联网、不会切换VPN。后端需明确确认参数，核对目标记录与USB已授权、无活动服务线程/自有转发、连接助手进程及VPN已停止；异常、状态不明、手机不在线、其他任务运行均拒绝并保留记录。只解除对应记录，保留其他手机、抓包结果和用户VPN配置。并发由服务锁保护，原有自动恢复与终止语义不变。

验收覆盖当前与历史记录、拒绝未经确认/错设备/离线/助手运行/隧道活动/本机worker未停止/并发和失败保留；桌面状态及确认弹窗；相关Python、Swift回归及隔离UI验收。真实手机操作仅只读，不自动清理用户现有记录；不发布或覆盖正在使用的桌面。

验收结果：Python 恢复及 API 回归 41 项、Swift 测试 211 项通过；隔离桌面使用模拟设备验证取消和确认，未操作真实手机或 VPN。
