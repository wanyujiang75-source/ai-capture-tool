# 模拟器弱网 V1

## 设计

- 主导航不变，在抓包页提供独立面板。当前场景固定为 2G、3G、4G、不限制，初始默认不限制；选择后点击应用，显示只读参数与当前生效参数，不再提供自定义输入。
- 测试预设（上传/下载 kbps、额外 RTT ms）：2G 128/256/600；3G 512/2048/150；4G 5000/10000/50。不限制通过原恢复 API 清除本工具规则，不提交高带宽配置。它们是确定性测试档位，不是运营商保证值，不改变无线制式。后端自定义 API 兼容保留；丢包/抖动/断网不属于本版。
- 切换页面后读取实际已启用档位，不能把活跃弱网误显示为不限制；轮询不能覆盖用户尚未应用的选择；恢复成功后选择器回到不限制。仅打开页面不自动发送修改请求。
- 网络范围是当前模拟器全部 wlan0/eth0 流量，包括 10.0.2.2 抓包通道。每个方向延迟 RTT/2，速率由 netem rate 控制。不修改 Mac 网络或 Android 全局代理。
- 使用设备 Root tc/netem 与专用 IFB 下行网卡；只允许 Android Emulator。拒绝覆盖已有非默认 root qdisc 或已有 ingress filter。保留系统 clsact；创建资源用固定可识别命名及句柄，并在修改前写入本项目恢复日志。
- root qdisc 使用独占 add 而非 replace；每个随机 IFB 的 alias 在 root/clsact 创建成功后记录归属，回滚必须核验归属。若在创建和归属标记之间异常退出，保留待恢复与技术诊断，不猜测删除同句柄的第三方规则；此极小窗口可能需要正常重启模拟器清除内核规则，不执行清除数据。
- 绑定 serial、AVD 名与 boot ID 防止序列号复用误操作。主机端服务锁串行修改，事务部分失败必须回滚；恢复失败保留日志，不显示已恢复。
- 恢复日志以 serial + AVD 为稳定键，恢复 runner 直接读取日志身份，不依赖发现设备时可能重排的 device-N。后台主动校验活动规则，即使离开抓包页，检测到设备断连后也会转为待恢复并重试。
- 服务启动恢复遗留设置并在后台重试；正常退出恢复。离线时保留待恢复，重连再恢复；boot ID 改变时旧 tc 规则已销毁，不误删新规则。
- 桌面正常退出先等待清理响应，最多 15 秒，再结束自有后端；超时保留恢复记录供下次启动重试。原 4 秒窗口在真实桌面并发轮询时不足，不能以孤立 API 的耗时替代原生退出验收。
- 仅桌面 UI 崩溃但后端存活时，RuntimeManager 首次接管经过 PID/路径/孤儿身份核验的同版本自有后端，调用 POST /api/desktop/recover-weak-network，仅恢复弱网，不停止抓包。重复检测同一后端不重复恢复，未知外部后端不被接管。
- API：GET /api/devices/{id}/weak-network；PUT 同路径应用配置；DELETE 同路径恢复。状态 enabled、pending_restore、available、message、profile、technical_detail。成功需读取规则确认。
- UI 请求绑定设备及请求代次；切换设备时不将旧响应写入新设备。失败说明保留页面，原始错误仅在技术详情中。

## 实施与验收

1. 后端 driver/service/router，安全归属和恢复状态测试先行。
2. Swift 模型/API/controller/panel 与预设应用、不限制恢复、错误、切换设备和选择同步回归。
3. 相关 Python 和 Swift 测试、构建并验证签名。
4. 设备真实 HTTP 小请求、512 KiB 上下行基线/弱网/恢复对比，确认速率和延迟效果；验证 SOCKS5 抓包路径及主机未限速。
5. 退出和重启恢复、离线待恢复测试；桌面实际开启/切换/恢复，最终无遗留规则。
6. 记录测量、命令、限制，更新用户说明，提交本地代码。

## 初始证据

- 基线 23afc5b；独立分支 codex/weak-network；代理回归 4/4 通过。
- 模拟器 36.2.12；内核含 NET_SCH_NETEM、IFB 等能力；设备 Root 可用。
- wlan0 root noqueue、eth0 root pfifo_fast，均有系统 clsact；wlan0 ingress 无 filter。须保留 clsact。
- 官方控制台网络参数仅承诺 Ethernet/Cellular，因此不用其承担 Wi-Fi 弱网：https://developer.android.com/studio/run/emulator-console
