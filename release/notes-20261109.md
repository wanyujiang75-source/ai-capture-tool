# 抓包工具 Desktop Preview 2026-11-09

适用于 macOS 14 及以上、Apple Silicon（M 系列）。开发预览版，使用 ad-hoc 签名，未经 Apple 公证；不支持 Intel Mac 或 Windows。不要关闭系统安全保护。

## 本版内容

- 同步当前开发分支，包含 Android 真机只读抓包条件检查模块；这不代表已支持免 Root 抓取所有线上 Release 应用。
- 保留接口过滤与搜索、Request/Response 格式化、断点编辑、Android 模拟器及 iPhone 抓包功能。本次原生界面未调整。
- 不包含修改后的 PokeHub APK。独立副本启动实验不属于本安装包的已验证功能。

## 升级前必读

**仅保留最近 7 次已结束或失败的抓包（Android/iPhone 合计），更早记录及对应文件将自动永久删除。** 需要历史数据时，先停止抓包并退出旧版，备份 `~/Library/Application Support/AI抓包工具/`。备份可能含 Token、Cookie，请勿公开分享。不要删除原证书、VPN 或模拟器配置。

## 安装与前置条件

1. 下载 Assets 中的 `AI-Capture-Desktop-…-development-arm64.zip` 和同名 `.sha256`，不是 Source code。
2. 在下载目录运行 `shasum -a 256 -c <校验文件名>`，确认 OK，解压后将“抓包工具.app”移入“应用程序”。
3. 首次启动若被 macOS 阻止，请在确认来源后按“系统设置 → 隐私与安全性”中的提示允许打开，不要全局关闭 Gatekeeper。
4. ZIP 内附 `安装说明.md`、`INSTALL.md` 和 `BREAKPOINTS.md`。Android SDK/系统镜像仍需按指南准备，未捆绑在应用中；访问公司 Jenkins 需要可达公司网络。
5. iPhone 仍需用户确认安装/信任测试证书及必要的转发选择；本包不会替你修改 VPN。升级前应停止记录，恢复原转发选择并确认联网，再退出旧桌面端。
