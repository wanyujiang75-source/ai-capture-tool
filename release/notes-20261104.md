# 抓包工具 Desktop Preview 2026-11-04

macOS 14+ / Apple Silicon（arm64）内部预发布版。使用ad-hoc签名，未经Apple公证；不能保证在所有新主机上免确认运行。

## 下载与安装

在本页Assets下载 `AI-Capture-Desktop-…-development-arm64.zip` 及同名 `.zip.sha256`；`Source code`不是可直接运行的App。
校验SHA-256后解压，将“抓包工具.app”移入“应用程序”。ZIP根目录同时包含“安装说明.md”和英文文件名“INSTALL.md”（内容相同，中文说明）。
首次若被macOS拦截，在系统“隐私与安全性”中本人确认“仍要打开”；不要关闭Gatekeeper或删除安全隔离属性。

## 本版内容

- iPhone真机统一HTTP(S)抓包：连接通过后直接开始，无需选择项目或逐个配置业务域名。
- 小火箭VPN保持开启，通过专用Capture-Mac节点临时统一转发；原节点参数、订阅和配置文件无需改写。流量经Mac出网，出口IP可能变化。
- 同一Mac有效期内复用证书与专用连接信息；重连必须重新验证手机，不会自动继续录制。
- 包内完整首次安装、证书信任、节点参数取得、日常使用、停止及恢复网络说明；首次需运行本机命令读取参数并生成不含Wi-Fi/VPN设置的证书副本，不是自动导入。
- 包含此前已完成的Jenkins安装包刷新优化、Android内嵌网页证书兼容及已合入源码的弱网场景。

## 已验证与边界

同一测试iPhone上的PokeHub、MelodyCraft、Wishly、StickerHub均取得业务Request/Response；后三款使用统一转发，未逐个新增域名。已验证停止记录及恢复原选择后的手机HTTPS联网。

手机安装/信任证书、首次添加专用节点、每次转发切换和恢复仍需本人操作。**停止抓包不等于恢复手机网络**：先停止记录，再恢复原节点/路由和曾手动设置的Wi-Fi代理，确认联网后才退出Mac工具。

仅使用iPhone不需要Android SDK；Android模拟器仍需SDK、合规Google Play镜像及环境准入。iPhone暂不支持安装应用、运行日志和弱网，不承诺所有设备/应用、证书绑定、自定义加密或非HTTP(S)协议可抓取，也不承诺保持原VPN出口IP或多手机并发。

升级请保留本机运行目录、钥匙串身份、模拟器和已有结果；不要将配置文件、节点密码或抓包中的Token/账号公开分享。
