# 抓包工具 Desktop Preview 2026-11-10

macOS 14+、Apple Silicon（M系列芯片）开发预览版。

- iPhone连接助手新增“导入抓包节点”：USB可用时尝试打开指定手机的小火箭导入确认；失败时提供二维码与当前手动参数。手机仍需确认添加，不自动切换VPN或路由。
- 默认发送仅证书及连接检查入口的配置，不修改Wi-Fi或VPN；补齐换电脑、换手机、IP变化时的操作指引。
- 保留接口过滤、请求/响应多行展示、断点和最近7次历史自动保留功能。升级前请另存需要长期保留的旧记录，超额历史会自动删除。

下载名称含development-arm64.zip的安装包，解压后将“抓包工具.app”移入“应用程序”。无需下载Source code。
安装与前置条件见包内INSTALL.md（或安装说明.md），详细使用及iPhone前置步骤见USER_GUIDE.md，断点见BREAKPOINTS.md。

本包为开发签名，未经过Apple公证。首次启动若被拦截，按安装说明在系统“隐私与安全性”中确认可信来源后打开，不要关闭系统整体安全保护。
iPhone需同网互通，证书安装/完全信任、手机节点确认与临时转发仍需本人完成；基本抓包不要求Xcode，USB自动导入受本机开发工具与设备授权条件影响，可改用手动方式。测试结束先恢复手机原节点和路由，VPN保持原样，再退出桌面。

已验证新机PokeHub业务Request/Response与隔离导入回退流程；未承诺所有iPhone/客户端版本或免Root Android线上包都可解密。
