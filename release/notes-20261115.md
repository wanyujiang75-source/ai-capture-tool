# 抓包工具 Desktop Preview 2026-11-15 · Android 网络与广告兼容

适用于 macOS 14+、Apple Silicon（M 系列）。开发签名预览版，未经过 Apple 公证。

## 更新内容

- Android 真机抓包前检查手机到 Mac 的连接与电脑代理出网，并区分连接建立和应用实际响应。
- Google Play 服务经电脑现有代理加密转发，不解密或记录其正文，改善跨进程登录的网络接入。
- StickerHub 启用限定的广告兼容策略：匹配的广告连接保持原 TLS 转发，业务接口仍采集请求与响应。不会根据失败日志自动扩大范围。

## 安装与使用

下载本页 `AI-Capture-Desktop-…-development-arm64.zip`。结束正在运行的抓包并退出旧版，解压后将 `抓包工具.app` 放入“应用程序”替换旧版；无需删除运行目录或手机数据。

ZIP 附带 `INSTALL.md`（安装与前置条件）、`USER_GUIDE.md`（Android/iPhone 操作）、`BREAKPOINTS.md`（断点说明）及中文安装说明。首次被 macOS 拦截时，请核对来源并按安装指南操作，不要关闭系统全局安全保护。

Android 手机与 Mac 连接同一 Wi-Fi，并通过 USB 授权调试；保持电脑现有 HTTP 代理可用。选择“Android → 真机”，按提示开始。手机连接助手会临时替换原 VPN；结束后确认原 VPN 已恢复，原节点和配置不修改。

## 验收与限制

- PKG110 上 StickerHub 正式版 3.18.15（196）冷启动抓包时 Banner 可见，20 组业务 RPC 请求/响应正文完整；134 项 Android 回归通过。
- 广告透传连接不展示解密正文；视频广告未完成验收，其他广告 SDK 仍可能出现 TLS 失败。不保证所有应用或版本兼容，也不保证广告每次填充。
- 不需要 Root、不改原安装包；HTTPS 解密仍取决于应用和系统版本的信任行为。
- iPhone 保留现有流程，本版没有新增 USB 描述文件安装功能。
