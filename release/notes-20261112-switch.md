# 抓包工具 Desktop Preview 2026-11-12 · 换机与流程终止

适用于 macOS 14+、Apple Silicon（M 系列芯片）。这是开发签名预览版，未经过 Apple 公证。

## 本次更新

- Android 真机新增“结束流程并重新检测”：终止当前任务并保留抓包记录，再识别新连接的手机。
- 拔线换机后的旧手机待恢复记录独立保留，不会误用于另一台设备；需要时连接原手机检查网络恢复。
- Android 入口统一为“模拟器 / 真机”，优化安装、授权、结束流程和恢复说明。

## 安装与使用

下载 `AI-Capture-Desktop-…-development-arm64.zip`，解压后将 `抓包工具.app` 放入“应用程序”。更新前先结束抓包并退出旧桌面；不要删除运行目录或手机数据。

ZIP 中附带 `INSTALL.md`（前置条件与安装）、`USER_GUIDE.md`（Android/iPhone 操作）和 `BREAKPOINTS.md`（断点说明）。首次打开若被 macOS 拦截，请按 `INSTALL.md` 核对来源并处理，勿关闭系统全局安全保护。

## 已知边界

- Android 真机的连接助手会临时替换原手机 VPN，仅抓取所选应用；原节点与配置不改，但其他应用不再受原 VPN 保护。结束后须确认原 VPN 恢复，不能同时保持两个 VPN 服务连接。
- 真机 HTTPS 解密受应用/系统版本和证书信任行为限制，不保证所有原版应用均可解密；现有兼容性限制保持。
- 旧手机离线时无法确认其网络恢复，桌面会保留提醒，不会自动操作新手机。
- iPhone 仍使用现有隔空投送配置流程；本版没有 USB 配置安装功能。
