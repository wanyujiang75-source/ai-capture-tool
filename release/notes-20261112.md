# 抓包工具 Desktop Preview 2026-11-12

macOS 14+ / Apple Silicon 开发预览版，新增 Android 真机实验入口，与模拟器明确区分。

## 本次更新

- USB 连接助手自动识别前台应用、准备单应用转发、归档 Request / Response；手机仅确认 USB 调试、安装及 VPN 授权。
- PokeHub、Wishly 的正式包和测试包已在 PHK110 通过桌面捕获业务 HTTP 200 与完整 JSON；仍存在部分连接无法解密。
- 优化操作说明，包含四步抓包、误拒绝后的重试、切换应用、换手机/电脑及原 VPN 恢复。
- 保留现有模拟器与 iPhone 链路；Android 真机使用独立运行时，不升级原抓包依赖。

## 下载与安装

下载本 Release 的 `development-arm64.zip` 和对应 `.sha256`，校验后解压，将“抓包工具.app”放入“应用程序”。先退出旧桌面端并恢复手机网络，再替换应用。无需下载 Source code。

包内含 `INSTALL.md` / `安装说明.md`、`USER_GUIDE.md`、`BREAKPOINTS.md`。本包为开发签名，未经 Apple 公证；首次被拦截时按安装说明在系统“隐私与安全性”确认来源后打开，不关闭系统安全保护。

## 实验限制

- 不 Root、不改原应用、不编辑原 VPN 节点/订阅/配置；临时接管会替换当前 VPN，其他应用不再由原 VPN 保护。只操作获准测试的应用。
- 解密依赖部分客户端的证书信任缺陷，不是通用方案；应用更新后可能失效，不要降级或关闭安全更新。
- 每轮最长 15 分钟。停止后部分机型需本人重连原 VPN，再点击“检查网络恢复”；PHK110 辅助恢复通过，不称全自动恢复通过。
- 授权未决取消、真实 USB 拔线和第二设备的最终停止协议仍待实机补验。真机模式暂不支持弱网、断点和 WebSocket 消息帧。
- 仅保留最近 7 次抓包记录，较旧记录会自动删除，请提前留存重要结果。

本次为实验预览，不表示功能已全面验收。2026-11-12 已将对应代码快进合并到主分支；安装包仍对应已校验构建 637a133，后续合并记录仅为文档变更。旧版下载保留。
