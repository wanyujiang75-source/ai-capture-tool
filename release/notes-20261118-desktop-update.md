- 主窗口工具栏在「运行检查」旁新增「更新」按钮。点开可以查看版本说明、下载桌面 ZIP，也可下载 SHA-256 校验文件。
- 安装本版后，后续预览包可从「更新」窗口查看和下载。

## 下载与升级

适用于 Apple Silicon（M 系列）Mac，macOS 14 或更新版本。本包使用开发签名，请按随包安装说明处理首次打开提示。

1. 在本页 Assets 下载 `AI-Capture-Desktop-20261118-32895f9-development-arm64.zip` 和同名 `.zip.sha256`。在下载目录执行 `shasum -a 256 -c AI-Capture-Desktop-20261118-32895f9-development-arm64.zip.sha256`，确认结果为 OK。
2. 如果已安装旧版，先结束抓包、恢复手机网络并退出旧版 App。
3. 解压 ZIP，将「抓包工具.app」拖入「应用程序」并选择替换。升级时保留原应用数据目录和 Android AVD。
4. 打开新版，在工具栏点击「更新」，即可看到更新说明和下载入口。
