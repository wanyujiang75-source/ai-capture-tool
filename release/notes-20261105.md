# 抓包工具 Desktop Preview 2026-11-05

macOS 14+ / Apple Silicon（arm64）开发预览版。使用ad-hoc签名，未经Apple公证；首次启动可能需要本人在“系统设置 → 隐私与安全性”确认“仍要打开”，不要关闭Gatekeeper。

## 升级前必读

**新版启动后仅保留最近7次已结束或失败的抓包，Android/iPhone合计计算。更早记录及对应抓包文件将自动永久删除，无法从工具中恢复。** 后续每次结束抓包也会自动清理；运行中的抓包不计入7次、不被删除。

如需保留旧结果，请停止抓包并退出旧版，在首次打开新版前，将 `~/Library/Application Support/AI抓包工具/` 复制到独立备份位置。备份可能含账号、Token或Cookie，不要公开分享。不要删除原运行目录、钥匙串身份、模拟器或原VPN配置。

## 本版更新

- 接口来源区分当前抓包和历史记录；历史窗口仅保留最近7次，显示明确状态。
- Request/Response分区展示参数、Headers与Body；JSON按层级缩进，键值对分行，支持连续选择复制；大正文保留有界预览。
- 历史自动清理同时删除索引和对应文件，保护活动任务、证书和原配置；删除失败保留索引并记录诊断，后续重试。
- 接口断点规则、待处理队列和请求/响应编辑界面；不开启断点不改变普通抓包流程。保留既有接口筛选、搜索及Android/iPhone抓包能力。

## 下载与使用

1. 在Assets下载 `AI-Capture-Desktop-…-development-arm64.zip` 及同名 `.zip.sha256`，不要选择Source code作为安装包。
2. 在下载目录执行 `shasum -a 256 -c <下载的校验文件名>`，显示OK后解压，将“抓包工具.app”移入“应用程序”。
3. ZIP附“安装说明.md”“INSTALL.md”（相同中文说明）和“BREAKPOINTS.md”（断点教程），包含系统要求、首次准备及网络恢复步骤。
4. iPhone升级前先停止记录并恢复原节点/路由、确认手机联网，再退出旧桌面端。手机证书信任和转发切换仍由本人确认；本次更新不要求修改原VPN配置。
